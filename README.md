# Разработка сервиса верификации юридически значимых электронных подписей

## Цель проекта
Создать высоконагруженный, отказоустойчивый микросервис, предназначенный для автоматизированной проверки юридически значимых электронных подписей (ЭП) и усиленных квалифицированных электронных подписей в составе архивов.

## Заказчик и бизнес-контекст
Крупная компания, которая ежедневно обрабатывает десятки тысяч юридически значимых документов, подписанных ЭП.

Существующие решения (локальные утилиты КриптоПро CSP, desktop-приложения) не позволяют:
- массово и автоматически проверять подписи в промышленных объёмах
- интегрироваться в существующие конвейеры обработки документов
- гарантировать юридическую значимость проверки в автоматическом режиме

## Основные пользователи системы
- Внутренние микросервисы компании

## Основные функциональные требования

1. Асинхронный приём задач из Kafka-топика.
2. Скачивание и распаковка zip-архива из S3.
3. Валидация структуры архива и XML-манифеста по XSD-схеме.
4. Автоматическая проверка всех электронных подписей с использованием КриптоПро CSP (утилита cryptcp) в headless-режиме.
5. Формирование подробного протокола проверки для каждой подписи:
   - статус подписи (действительна / недействительна / ошибка)
   - данные сертификата (владелец, издатель, срок действия, ОГРН/ИНН)
   - наличие/отсутствие валидной цепочки до корневого УЦ
   - наличие в списках отзыва (CRL) и OCSP-ответ
   - временная метка (при наличии)
6. Запись результатов проверки в БД.
7. Публикация результата обработки в исходящий Kafka-топик.
8. При успешной проверке всех подписей в архиве — перемещение архива в «проверенный» бакет S3 с добавлением метаданных.
9. Ведение полного лога операций (уровень INFO/ERROR) с сохранением в централизованную систему логирования.

Сервис разрабатывается с учётом реального промышленного использования и уже частично внедрён в среду компании.
